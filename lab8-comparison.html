Bootstrap ба Tailwind CSS

Хоёр framework-ээр хийсэн ижил ёоёоны цомгийг бүтэц, хөгжүүлэлтийн арга, Lighthouse-ийн хэмжилтээр харьцуулав.

Үндсэн ялгаа

Үзүүлэлт Bootstrap Tailwind CSS
Ажиллах арга Урьдчилан бэлдсэн component болон utility class ашиглана. Utility class-уудаар элемент бүрийн загварыг HTML дээр шууд тодорхойлно.
Хөгжүүлэлтийн хурд Navbar, button, form зэрэг түгээмэл component хурдан угсарна. Загварыг нарийн тохируулна; эхэндээ олон class бичих шаардлагатай.
Загварын уян хатан байдал Bootstrap-ийн үндсэн хэв маяг давамгайлна; өөрчлөхдөө нэмэлт CSS хэрэглэж болно. Өнгө, зай, хэмжээ, breakpoint-ийг utility болон theme-ээр нарийн тохируулна.
Responsive дизайн Grid болон responsive class-ууд ашиглана. Breakpoint prefix, жишээ нь sm:, md:, lg: ашиглана.
Нэг картын class тоо 4 — картын үндсэн element дээрх class-ууд. 11 — картын үндсэн element дээрх class-ууд.
Framework CSS хэмжээ 232.6 KB — Bootstrap 5.3.3 CDN Бодитоор хэмжсэн tailwind-output.css

Class-ын тоо нь одоогийн хуудсын нэг картын үндсэн элемент дээрх class-уудыг тоолсон жишээ. HTML-ээ өөрчилсөн бол өөрийн хувилбараас дахин тоол.
